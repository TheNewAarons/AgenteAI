# Stack Tecnológico Preferido

## Lenguajes de Programación
- **Principal**: Python 3.x
- **Frontend**: JavaScript (ES6+), HTML5, CSS3
- **Secundario**: SQL, Bash

## Frameworks y Librerías

### Backend
- **Flask** — Web framework principal (Python)
- **FastAPI** — Para APIs de alto rendimiento (cuando se requiera)

### Frontend
- **Vanilla JS** — Preferido para proyectos simples
- **Bootstrap 5** — Componentes UI reutilizables
- **Marked.js** — Renderizado de Markdown
- **Mermaid.js** — Generación de diagramas

### IA / Integración
- **Google Gemini API** (google-generativeai SDK) — Modelo de IA principal
- **python-dotenv** — Gestión de variables de entorno

## Bases de Datos
- **PostgreSQL** — Base de datos relacional preferida en producción
- **MySQL** — En ambientes académicos o proyectos heredados
- **SQLite** — Para proyectos pequeños o prototipado
- **MongoDB** — Para datos no estructurados (uso secundario)

## DevOps y Herramientas
- **Git + GitHub** — Control de versiones
- **Docker** — Contenedores (básico)
- **GitHub Actions** — CI/CD básico
- **Postman / curl** — Testing de APIs

## Entorno de Desarrollo
- **SO**: macOS
- **Editor**: VS Code (con extensiones de Python y JS)
- **Terminal**: zsh
- **Gestor de paquetes Python**: pip + venv

## Para Futuro Aprendizaje
- AWS (EC2, S3, Lambda)
- Kubernetes
- Terraform
